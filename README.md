> **DanceFlow** is an interactive dance studio management and class scheduling web platform. It enables dancers to browse workshops, reserve session passes, and follow instructors across classical, contemporary, and hip-hop styles.

---

## ✨ Features

- 🗓️ **Interactive Class Timetable:** Filter sessions by skill level, instructor, and dance genre.
- 🎫 **Workshop Pass Booking:** Streamlined ticket booking with instant confirmation dialogs.
- 📱 **Mobile-First Experience:** Fluid touch gestures for quick schedule browsing on smartphones.

---

## 🚀 Quick Start
```bash
git clone https://github.com/sangamesh5588/dance-flow-app.git
cd dance-flow-app
npm install
npm run dev
```
